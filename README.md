# Cozyday

App iPhone cá nhân: sắp xếp một ngày thành timeline, hoàn thành việc để chăm chú mèo và trang trí góc phòng.
Viết bằng Swift + SwiftUI + SwiftData, chạy offline, không tài khoản, không máy chủ.

> Trạng thái: **Mốc A — kiểm chứng đường cài**. Xem `PROJECT_STATUS.md`.

Hướng dẫn cài (Windows → GitHub Actions → Sideloadly → iPhone): `docs/INSTALL_WINDOWS_IPHONE_VI.md` (đang soạn).
